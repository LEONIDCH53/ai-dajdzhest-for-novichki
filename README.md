# AI-дайджест для новичков

Конверсионный сайт на Flask с 10 готовыми материалами об ИИ для тех, кто начинает.
Тёмная тема, адаптивная вёрстка, плавные анимации. Запуск одной командой.

**Репозиторий:** [LEONIDCH53/ai-dajdzhest-for-novichki](https://github.com/LEONIDCH53/ai-dajdzhest-for-novichki)

---

## Что нужно установить

Два программных компонента:

| Что | Зачем | Ссылка |
|-----|-------|--------|
| **Python 3.8 или новее** | язык, на котором написан сайт | <https://www.python.org/downloads/> |
| **Git** | скачать репозиторий с GitHub | <https://git-scm.com/downloads> |

При установке Python на Windows **обязательно поставьте галочку «Add Python to PATH»** —
это самый частый источник ошибок у новичков.

Проверьте, что всё установилось. Откройте терминал и выполните:

```bash
python --version
git --version
```

Обе команды должны показать версию. Если вместо версии видите ошибку «command not found»
(или «не является внутренней или внешней командой») — вернитесь к шагу установки
и проверьте галочку про PATH.

## Установка за 4 шага

### Шаг 1. Скачайте репозиторий

Откройте терминал в папке, где будет лежать проект, и выполните:

```bash
git clone https://github.com/LEONIDCH53/ai-dajdzhest-for-novichki.git
```

### Шаг 2. Перейдите в папку проекта

```bash
cd ai-dajdzhest-for-novichki
```

### Шаг 3. Создайте виртуальное окружение и поставьте Flask

Окружение — это отдельная «песочница» для зависимостей проекта. Оно нужно, чтобы
пакеты сайта не смешивались с остальными программами на компьютере.

Для Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Для macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

После активации в начале строки терминала появится `(.venv)` — значит, всё работает.

Теперь поставьте Flask:

```bash
pip install -r requirements.txt
```

> Нужна именно эта команда: она читает файл `requirements.txt` и ставит ровно те версии,
> которые использовались при разработке. Отдельный `pip install flask` может поставить
> другую версию, и сайт сломается.

### Шаг 4. Запустите сайт

```bash
python app.py
```

Готово. Откройте в браузере: **<http://127.0.0.1:5000>**

Остановить сервер: нажмите `Ctrl + C` в терминале.

## Страницы сайта

| Адрес | Что показывает |
|-------|----------------|
| `/` | главная: герой, 10 карточек, фильтры, преимущества, отзывы, FAQ, форма подписки |
| `/material/<slug>` | страница материала: краткое резюме, объяснение, шаги, словарь терминов, практика |
| `/subscribe` | приём email из формы (POST) |
| любое неверное имя | страница 404 |

Примеры адресов материалов:

- `/material/chto-takoe-ii` — что такое ИИ простыми словами
- `/material/prompty` — как правильно спрашивать ИИ
- `/material/plan-7-dney` — план на 7 дней

## Как поменять содержимое

Весь текст и все карточки лежат в одном файле — `data.py`. Ничего больше трогать не нужно.

**Поменять текст карточки.** Найдите нужный словарь в списке `MATERIALS` и отредактируйте
значения. Например, чтобы сменить заголовок:

```python
{
    "slug": "prompty",
    "title": "Промпт: как правильно спрашивать ИИ",   # ← это
    ...
}
```

**Добавить новый материал.** Скопируйте любой блок из `MATERIALS`, вставьте рядом и
поменяйте `slug` на новый уникальный адрес. Сайт сразу покажет карточку, а кнопка
«Открыть материал» заработает сама.

Поля блока:

| Поле | Что это |
|------|---------|
| `slug` | часть адреса страницы, латиницей, без пробелов |
| `title` | заголовок карточки и страницы |
| `lead` | короткое описание, видно в карточке |
| `emoji` | иконка карточки |
| `tag` | тема для фильтра, должна совпадать со списком `CATEGORIES` |
| `accent` | цвет: `violet`, `cyan`, `pink`, `lime`, `amber` |
| `level` | сложность: «Совсем с нуля» |
| `time` | время чтения, например «8 мин» |
| `bullets` | список из трёх пунктов «что вы узнаете» |
| `what` | абзацы с объяснением |
| `steps` | пошаговая инструкция |
| `terms` | словарь терминов, пары «слово — значение» |
| `practice` | мини-задание в конце |
| `link`, `link_label` | внешняя ссылка на официальный сайт сервиса |

## Как поменять цвета и фон

В начале файла `static/css/style.css` есть блок `:root` — все цвета сайта собраны
в переменных. Достаточно поменять значение в одной строке:

```css
:root {
    --bg:   #07070d;   /* основной тёмный фон */
    --text: #f3f4fa;   /* цвет текста */
    --a1:   #a78bfa;   /* первый цвет карточек */
    --a2:   #6d4aff;   /* второй цвет карточек */
}
```

Цвета карточек заданы в самом конце файла в строках `.accent-violet`, `.accent-cyan`
и так далее.

## Частые проблемы

**`ModuleNotFoundError: No module named 'flask'`**
Не установлен Flask или не активировано виртуальное окружение. Выполните
`python -m venv .venv`, активируйте его и снова поставьте зависимости:
`pip install -r requirements.txt`. Проверить, что окружение активно, можно командой
`pip list` — в списке должен быть Flask.

**`Address already in use` / порт 5000 занят**
Порт занят другой программой. Откройте `app.py` и в последней строке замените
`port=5000` на свободный, например `port=5001`. Затем откройте в браузере
`http://127.0.0.1:5001`.

**При запуске `python app.py` открылось окно с ошибкой про Python Store**
У вас установлен «Microsoft Store» вместо Python. Скачайте настоящий Python
с <https://www.python.org/downloads/>, отметьте «Add Python to PATH» при установке
и перезапустите терминал.

**`python` не находит файл app.py**
Вы находитесь не в папке проекта. Выполните `cd ai-dajdzhest-for-novichki`
или откройте терминал прямо в этой папке.

**Шрифт или градиенты выглядят иначе**
Шрифты и Google Fonts подгружаются из интернета. Без сети используется запасной
системный шрифт — сайт останется рабочим, но чуть проще на вид.
